# The ZX Spectrum 48K ROM

`48.rom` is the original Sinclair ZX Spectrum 48K ROM (16384 bytes, MD5 4c42a2f075212361c3117015b107ff68),
© 1982 Sinclair Research Ltd, now © Amstrad.

Amstrad have kindly given their permission for the redistribution of their copyrighted material (the Spectrum
ROMs) with emulators, but retain that copyright. The copyright messages in the ROM are unchanged.

ZX47 builds it into the program (`make` turns it into `build/gen/rom48.c`).
